# www/ — the old Reva wiki (deprecated)

These pages document the original 32-bit x86 distribution (install paths
under `bin/`, `LD_LIBRARY_PATH`, prebuilt IUP libraries, x86 internals) and
are **deprecated**. Current documentation is in [`../docs/`](../docs/),
rebuilt from the portable implementation with executable, tested samples.

[`../docs/parity.md`](../docs/parity.md) tracks every page and section here:
what has been rebuilt, what is waiting on the port, and what no longer
applies. The pages stay unchanged for reference until parity is reached;
then they move to `legacy/www/` and are later deleted, each as its own
change (see [`../DEPRECATED.md`](../DEPRECATED.md)).
