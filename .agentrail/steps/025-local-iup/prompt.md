The virtual library iup (the C functions lib/ui/iup and lib/ui/gui bind: IupOpen, IupDialog, IupVbox, IupHbox, IupLabel, IupButton, IupText, IupSetAttribute, IupStoreAttribute, IupGetAttribute, IupSetCallback, IupShow, IupShowXY, IupHide, IupDestroy, IupPopup, IupMainLoop, IupFileDlg, ...) over components/ui's model, pointer-free where the binding allows (handles as integers; strings copied). IupMainLoop and IupPopup become event waits (a host call that pauses the VM until a UI event; the callback's Forth xt then runs, returning IUP_DEFAULT/IUP_CLOSE). A headless host in tests drives events. Goldens: examples/iup/hello-world.f, simple-button.f and a scripted Tui-like session. Rules: as the component steps (<=4 modules/crate, <=4 crates/workspace, facades-only lib.rs, tests in tests/, pure functions, macros/tables for boilerplate, loose coupling). Not a wrapper of IUP and nothing of IUP redistributed: a reimplementation of the API Reva programs use. Gate: just check; goldens unchanged except new ones. One PR to dev.
