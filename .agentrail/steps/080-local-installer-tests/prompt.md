Test the installers and the installed app on Windows, macOS and Linux (the user, 2026-11-22, from CoSy's ask 28; GitHub Actions). A CI job per OS that, for the installer local-desktop-installers builds: installs it silently on the clean runner (the NSIS setup.exe /S, the .dmg mounted and copied, the .deb with apt); starts the installed app headless or under a virtual display and checks it: --about and `version` (package and reva-fork versions, commit), a script run in the window (a file written to the user's folder, `save` then restart then check), an IUP dialog and CD drawing in the installed app's page (pixels, as cd-pixels), with screenshots kept as artifacts; installs the next version over it and checks the user's folder is kept; uninstalls and checks the user's folder is still there. The same checks as a script for a by-hand run on an installed app (tests/check-installed.sh and a .ps1 for Windows), which CoSy's check-release.sh --installed can call. The browser (wasm) page and the CLI keep their own checks on all three OSes. Record each OS's result in docs/packaging.md.
