The CLI backend of the TUI's cell grid (local-ui-grid; option 2, decided with the user 2026-10-31): the crossterm crate (MIT) for raw mode, key and mouse events, resize, and drawing the grid with colours, redrawing only changed cells. CoSy's Tui.f (three edit panes: text, result, state; a stack status line; buttons; F-keys: F6 evaluates the current line, sF6 the selection, F8/F9 send a line) and the simple examples/iup programs run in a terminal exactly as in the browser and the desktop app. Same model, same Forth, no program changes; goldens through the grid, a manual check at a real terminal (Terminal.app, iTerm, a Linux terminal), restoring the terminal on exit or fault.
