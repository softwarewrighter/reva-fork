Graphics for IUP programs, in the browser and the desktop app (not the CLI terminal; the user, 2026-10-30). Reva drew through IUP's canvas[ widget and Tecgraf's CD library (lib/ui/cd binds ~150 cd* functions: lines, boxes, arcs/chords, polygons with cdBegin/cdEnd, text and fonts, colours, fill and line modes, clipping, images/bitmaps), repainting from the canvas's ACTION callback, animating with timers, with mouse/key callbacks. Reimplement the CD functions examples use as a virtual library drawing into the turtle's display list (components/canvas: new op records for rectangles, arcs, polygons, fill, text, images; SVG export extended), shown by a canvas pane of the Yew renderer with the canvas callbacks (redraw, resize, mouse, keys, timers) wired back to Forth. Parity: examples/iup binary-clock, brownian and cd-test run unchanged in the browser and the desktop app. Out of scope: CD's PDF/printer contexts, OpenGL (ui/gl, glu, glut).
