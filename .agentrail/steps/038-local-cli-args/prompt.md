Feature (found 2026-10-30 by the sha1.f parity change): original Reva included only argv[1] and left the rest of the command line to the program (examples/sha1.f hashes argv[2..]); reva-cli treats every positional argument as a file to include, so programs that take arguments cannot get them. Add 'reva prog.f -- arg ...' (and keep 'reva a.f b.f' as it is): after --, the words become argv[2..] and argc counts them, as the original did. Document it (docs/getting-started.md, --help), a golden for argc/argv, and give parity-examples.sh a way to pass arguments to examples that need them (sha1.f with a real file), so it becomes a passing, timing-independent row.
