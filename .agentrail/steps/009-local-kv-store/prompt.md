A key-value store for every host (rust/DESIGN.md 3.11), the browser's answer to db/sqlite. Forth vocabulary lib/db/kv (needs db/kv): open a named store, put/get/delete a key (strings or byte blobs), list keys, close; errors through ioerr-style codes. Served by host calls: the browser page from localStorage under the package's prefix (Web Workers have no localStorage, so the page answers), the CLI and the desktop from reva-sqlite (one table per store in a database file in the VM's folder). Same behaviour everywhere: a golden on the CLI, the web smoke test in node, the desktop smoke test. Docs: docs/kv.md with a REPL example, web.md, parity.md (new in the portable core).
