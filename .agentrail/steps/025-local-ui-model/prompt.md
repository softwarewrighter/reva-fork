The UI model for IUP programs (decided with the user 2026-10-28: reimplement IUP for Reva in Rust, rendered with Yew, so lib/ui/gui and CoSy's Tui.f run unchanged). A new component components/ui: a pure Rust model of an IUP element tree (dialog, vbox, hbox, label, button, text/multiline editbox, list, spacer/fill, menu, file dialog), attributes as IUP names them (TITLE, SIZE, EXPAND, VALUE, CARET, SELECTION, TIP, TOPMOST, ...), callbacks by name (ACTION, K_* keys, ...), layout rules, and a serializable change stream for renderers; tested on its own, no VM. Read lib/ui/iup, lib/ui/gui and ba-cosy-zip-fork's sample/CoSy/Tui.f (33 gui words used) and examples/iup/ to fix the scope; record it in docs. Rules: as the component steps (<=4 modules/crate, <=4 crates/workspace, facades-only lib.rs, tests in tests/, pure functions, macros/tables for boilerplate, loose coupling). Not a wrapper of IUP and nothing of IUP redistributed: a reimplementation of the API Reva programs use. Gate: just check; goldens unchanged except new ones. One PR to dev.
