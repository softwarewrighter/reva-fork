Feature: GitHub Actions running `just check` on macos-latest and ubuntu-latest for pushes and PRs to dev and main, with caching for cargo and the tools (reg-rs, sed-rs, cargo-deny). Linux needs WebKitGTK 4.1 for the desktop build and Xvfb for its smoke test. Mac-only regressions so far (sed, bash 3.2, the smoke banner, scrolling) are what this is for.
