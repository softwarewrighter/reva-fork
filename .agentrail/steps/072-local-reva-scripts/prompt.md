Feature (the user, 2026-10-30): Reva scripts. A file starting with '#!/usr/bin/env reva' (or the path of reva) runs as a Unix program: the #! line is skipped; script mode (the first file starts with #!) makes the remaining words argc/argv (building on local-cli-args) instead of files to include; stdin is data, not Forth source: readable through fd 0 (read, and a line reader), stdout/stderr are fds 1/2, no banner/prompt/ok>, 'bye' (and a word for an exit status) end it with the status; errors go to stderr with a non-zero status. Document it (docs/scripts.md). Demos as simple proofs of concept in examples/scripts/: head, tail, wc, grep (with -n/-c style options where easy), each runnable as ./head.f FILE and in a pipe (cat x | ./wc.f); goldens that pipe data through each; a short demo in docs. Keep VM changes out of it if possible: CLI and host plumbing.
