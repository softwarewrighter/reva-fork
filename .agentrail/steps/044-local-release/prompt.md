Feature: the release process. A `just bump` that sets the version (YYYY.MMDD.N; Cargo forbids leading zeros, so January 5 is 2026.105.0) and updates the goldens that contain the banner; a git tag; a GitHub release with CLI binaries for macOS (arm64, x86_64), Linux and Windows, the web zip, and the macOS dmg. Signing and notarization need the user's Apple Developer ID: decide with the user. Document in docs/packaging.md.
