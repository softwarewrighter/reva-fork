SQLite in the browser (rust/DESIGN.md 3.11). Decided with the user (2026-10-27): do not redistribute SQLite; the VM's worker loads SQLite's official wasm build at run time from jsDelivr, pinned (@sqlite.org/sqlite-wasm@3.54.1-build1; CORS *, application/wasm, immutable), the first time a program uses SQLite, and answers the 'sqlite' host calls itself (sqlite.js) with the same operations and codes as reva-sqlite. Databases persist in the browser's private file system (OPFS) and survive a reload; offline: a clear 'SQLite could not be loaded' stop; the desktop keeps answering natively.
