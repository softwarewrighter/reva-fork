At the user's request (2026-11-01): 'help' prints real documentation in the CLI, the desktop app and the browser. The original reads a SQLite help.db built from the def: docs (tools/genhelp.f); the port finds none at /reva/bin/ and prints only the word's name. Build a help index at build time from src/help.txt and the def: entries in lib/ (so new libraries such as ui/notebook are covered), embed it, and make 'help WORD' show what the original showed (stack picture, context, version, source, description; 'no help' for unknown words). Goldens that test the content: help dup, help see, help notebook, an unknown word, and a check that every documented word is found. Gate: just check.
