A Rust/Yew renderer for components/ui's model, in the web page and the desktop app (a new component, e.g. components/ui-yew, compiled to wasm beside the VM's module): the dialog tree as DOM, attributes applied, user events (clicks, edits, keys incl. F1-F12, caret/selection) sent back as the iup host-call answers; themed like the REPL page; the canvas pane keeps working. Verified in Chrome and the desktop app with examples/iup programs. Rules: as the component steps (<=4 modules/crate, <=4 crates/workspace, facades-only lib.rs, tests in tests/, pure functions, macros/tables for boilerplate, loose coupling). Not a wrapper of IUP and nothing of IUP redistributed: a reimplementation of the API Reva programs use. Gate: just check; goldens unchanged except new ones. One PR to dev.
