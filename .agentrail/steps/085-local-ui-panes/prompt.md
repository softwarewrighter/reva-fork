Stage 2 of the UI, a longer-term goal building on the Notebook (local-ui-model .. local-ui-terminal; not the other way round; the user, 2026-10-30): a tmux/Emacs-inspired layout. Split a pane horizontally or vertically, resize, move focus, zoom one pane to the full window and back to the multi-pane view; pane kinds: a REPL (several possible), an editor (load/save a file; evaluate the line or selection into a REPL, as the Notebook does), a tail (follow a file or another pane's output), and an IUP dialog. Key bindings documented; the same layout model rendered by the Yew page (browser, desktop) and the terminal renderer (CLI). Demo: edit a file in one pane, tail a log in another, a REPL in a third, zoom and unzoom, at CLI, desktop and browser.
